# Восстановление файлов с флешки

Скрипт ищет удалённые файлы на флешке после форматирования: фото, видео,
документы и архивы. Флешку он только читает и ничего на неё не пишет.

## Сначала главное

- **Ничего не записывайте на флешку.** Каждая запись может навсегда затереть
  старые файлы.
- Восстановленные файлы сохраняйте **на другой диск** (например, `D:`).
  На ту же флешку скрипт сохранять не даст.

## Что понадобится

1. Python 3 с [python.org](https://www.python.org/downloads/). При установке
   отметьте галочку **«Add python.exe to PATH»**.
2. Свободное место на другом диске: примерно объём флешки (под её копию)
   плюс место под найденные файлы.

## Как запустить

1. Скачайте папку `recover` (файлы `recover.py` и `recover.bat`) на компьютер,
   **не на флешку**.
2. Вставьте флешку. Если Windows предложит её отформатировать, нажмите **«Отмена»**.
3. Дважды кликните `recover.bat` и разрешите запуск от администратора.
4. Ответьте на вопросы:
   - буква флешки (например, `E`);
   - папка для результата на другом диске (например, `D:\recovered`);
   - делать ли копию флешки: ответьте **Д**, это безопаснее. Скрипт один раз
     скопирует флешку в файл `flash.img` и дальше будет работать с копией.
5. Дождитесь окончания. Найденные файлы лежат в `D:\recovered\files\`,
   разложенные по папкам `jpg`, `mp4`, `docx` и т.д.

## Что восстанавливается

| Тип | Форматы |
|---|---|
| Фото | JPG, PNG, GIF, BMP, HEIC, WEBP |
| Видео и звук | MP4, MOV, 3GP, MKV, WEBM, AVI, WAV, M4A |
| Документы | PDF, DOCX, XLSX, PPTX, DOC, XLS, PPT, ODT, ODS, ODP, EPUB |
| Архивы | ZIP, RAR, 7Z |

## Чего ожидать

- **Имена файлов и папки не восстанавливаются.** Форматирование стирает их
  первыми, поэтому файлы получат номера: `00012.jpg`. Чтобы найти нужное,
  отсортируйте по размеру или откройте папку с типом и посмотрите эскизы.
- **Часть файлов может открыться с ошибкой.** Чаще всего это большие видео,
  если на флешке они лежали кусками (фрагментированы).
- Обычные `.txt` не находятся: у простого текста нет «подписи», по которой
  его можно узнать.
- Если флешку форматировали **без** галочки «Быстрое», Windows заполнила её
  нулями, и восстановить, к сожалению, нечего.

## Если что-то не так

- «Нет доступа» — запускайте через `recover.bat`, а не `recover.py`.
- «Не найдено» — проверьте букву флешки в «Этом компьютере».
- Если флешка вообще не определяется, читается с ошибками или нужное не
  нашлось, а данные очень важны — не экспериментируйте дальше и отнесите
  флешку в сервис по восстановлению данных.

## Для продвинутых

```
python recover.py image E: D:\flash.img      # копия флешки в файл
python recover.py carve D:\flash.img D:\out  # поиск файлов в копии
python recover.py carve PhysicalDrive2 D:\out
```

Проверка скрипта: `python recover/test_recover.py`. Тест собирает
искусственную «отформатированную» флешку с файлами разных форматов и
проверяет, что каждый файл восстанавливается байт в байт.
